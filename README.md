# kogason2010 Lab

A 3D analytical chemistry lab, built with Three.js, that works as a portfolio.

- Click an instrument (HPLC, Nexera IC, TOC analyzer, reagent cabinet, whiteboard) to zoom in and open its panel.
- Click the monitor to go to [KogasonOS](https://kogason2010.github.io/), the desktop portfolio.
- **Particles** turns the lab into a point cloud that forms a caffeine molecule.
- **Lights off** shows the lab after hours.

Everything is drawn in code. There are no model files, so the whole lab is one `index.html`.
